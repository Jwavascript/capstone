# 디자인 레퍼런스 조사: AI 요약 중심 뉴스 서비스(웹)

- 조사 일자: 2026-10-07
- 대상 SPEC: 네이버 뉴스 이슈 랭킹 대시보드 (6개 섹션 x Top 5 이슈, AI 3줄 요약, 연관기사 수, 북마크, 날짜 선택, 로그인)
- 조사 범위: AI가 기사를 묶어 요약 카드로 보여주는 웹 기반 뉴스 서비스. 해외 서비스 위주 + 국내 앱형 서비스 검색 확인.

## 확인 방법과 한계

- 도구: WebFetch(페이지를 마크다운으로 변환 후 소형 모델이 요약한 결과), WebSearch. **실제 브라우저로 스크린샷을 보지 못했습니다.** 따라서 색상, 글꼴, 여백 등 시각 스타일의 수치는 직접 확인하지 못했고, 해당 항목은 모두 "미확인"으로 표시했습니다. 구조(헤더/내비/카드 구성요소)는 WebFetch가 읽어온 텍스트 기준입니다.
- 접속 성공: news.kagi.com, particle.news, ground.news, tldr.tech
- 접속 차단/실패:
  - newsminimalist.com: HTTP 429 (2회 시도 모두). 내용은 검색 결과로만 보완 -> **미확인**
  - boringreport.org: ECONNREFUSED(1회), 429(1회). 운영 여부 확인 불가 -> **미확인**
  - perplexity.com/discover: HTTP 403
  - newsming.ai: 도메인 없음(DNS 실패). 뉴밍/도비뉴스는 검색 결과상 앱스토어 앱으로만 확인됨
- 시각 스타일 확인 불가: 실제 구현 전에 사용자가 브라우저로 직접 열어 색/글꼴을 확인해야 합니다.

## 추천 1순위: Kagi News

- URL: https://news.kagi.com
- 개요: 수백~수천 개 RSS를 하루 1회(검색 결과 기준 12:00 UTC) 수집해, 같은 사건 기사를 하나의 스토리로 묶고 AI가 요약. 광고/추적/무한스크롤/로그인 없음(검색 결과, 부분 미확인).
- 구조는 SPEC(하루 1회 수집, 이슈 묶음, 카테고리별 구성)과 가장 일치.

### 화면 구성 (WebFetch 텍스트 기준)
- 헤더: "Kagi News" 브랜드, "Updated 12 hours ago" 형태의 갱신 시각, "125720 news today" 같은 통계, "You've read 0 stories" 읽음 진행도, "Week 40, Day 280 / Wednesday, October 7" 날짜 표기.
- 내비게이션: 상단 가로 메뉴(Kagi 서비스 링크: Search, Assistant, News, Translate, Summarize, Small Web, FastGPT). 카테고리: World, USA, Business, Technology, Science, Sports, Gaming, Today in History, Public Health.
- 메인 레이아웃: 카테고리별 스토리 카드 피드. 열 수/그리드 값은 **미확인**(텍스트 추출로는 알 수 없음).
- 카드 구조: 카테고리 라벨, 헤드라인, 짧은 설명. 스토리 상세에는 하이라이트, 출처 목록(링크+본문 내 인용), 관점, 배경, 타임라인이 있다고 검색 결과에 나옴. 공개 데이터 스키마(kite-public 문서)에는 title, short_summary, talking_points, number_of_titles, unique_domains, articles, category, emoji, primary_image 등이 있음 -> **number_of_titles/articles가 연관기사 수에 해당**.
- 푸터: "Mark all as read", Contribute, About Kagi News, Feedback, RSS 링크+아이콘.

### SPEC 기능 대응표
| SPEC 기능 | 대응 | 비고 |
|---|---|---|
| 섹션별 랭킹 | 부분 | 카테고리 섹션은 있으나 Top 5 연관기사 수 랭킹은 아님(순서 기준 미확인) |
| 이슈 묶음/연관기사 수 | 부분 | 클러스터링 있음, 기사 수 데이터 필드 존재. 화면 노출 형태는 미확인 |
| 요약 | 있음 | 단, 3줄이 아니라 길고 다층적 |
| 날짜 조회 | 미확인 | 오늘 날짜 표기만 확인, 날짜 선택기는 확인되지 않음(없음으로 추정) |
| 갱신 시각 | 있음 | "Updated N hours ago" |
| 로그인 | 없음 | 로그인 불필요 |
| 북마크 | 없음 | "읽음 표시"만 있음 |
| 반응형 | 미확인 | 모바일 앱/웹 존재는 검색상 언급, 레이아웃 미확인 |

### 시각 스타일
- 색/글꼴/여백/아이콘: **미확인**(스크린샷 불가). 이모지 필드와 RSS 아이콘 사용 정도만 확인. 미니멀한 정보 중심 톤이라는 점은 기사들의 서술 기준(2차 정보).

### 그대로 가져올 부분 / 바꿀 부분
- 가져올 것: 헤더의 갱신시각+오늘 통계 배치, 카테고리 단위 구성, 카드 내 카테고리 라벨+헤드라인+요약 구조, 광고 없는 정보 중심 톤, 푸터 구성.
- 바꿀 것: 6개 섹션을 한 화면 그리드(데스크톱 3열x2행)로 재구성, 섹션당 Top 5 랭킹 번호와 연관기사 수 배지, 요약 3줄 고정, 날짜 선택기/오늘 버튼, 로그인, 북마크, 북마크 전용 페이지는 신규 제작. 한국어 UI.

## 추천 2순위: Particle

- URL: https://particle.news
- 개요: AI가 여러 매체 기사를 묶어 요약하는 뉴스 서비스. 운영사 Mina Labs, Inc.(푸터 저작권 2026 확인). 웹+앱.

### 화면 구성 (확인된 텍스트 기준)
- 헤더: 로고, "Get Newsletter", "Sign in".
- 내비게이션: 1단 카테고리 탭(Popular, Technology, Sports, Entertainment, Science, Politics, Crime, Economics, Video Games). 2단: 큐레이션 토픽 모음(Top News 등 시사 이슈 컬렉션). 하단 토픽 태그 분류.
- 메인 레이아웃: 카드 기반. 열 수는 **미확인**.
- 카드 구조: 썸네일(640x640 WebP), **기사 수 배지**, 게시 시각, 헤드라인, 짧은 설명.
- 푸터: Blog, Jobs, Terms, Privacy, Cookies, Help, Partners, About Us, 저작권. 모바일 앱 다운로드(Google Play/App Store) 버튼.

### SPEC 기능 대응표
| SPEC 기능 | 대응 | 비고 |
|---|---|---|
| 섹션별 랭킹 | 부분 | 탭 방식, 섹션 동시 표시 아님 |
| 이슈 묶음/연관기사 수 | 있음 | 기사 수 배지 |
| 요약 | 있음 | 카드에는 짧은 설명, 상세 요약은 미확인 |
| 날짜 조회 | 미확인 | 확인되지 않음 |
| 갱신 시각 | 부분 | 카드별 게시 시각, 전체 갱신 시각은 미확인 |
| 로그인 | 있음 | Sign in |
| 북마크 | 미확인 | 로그인 기능 존재, 저장 기능 화면 미확인 |
| 반응형 | 있음(부분) | 모바일 지원 언급, 세부 미확인 |

### 시각 스타일
- 색/글꼴/여백: **미확인**. 썸네일 이미지 중심 카드라는 점만 확인.

### 가져올 부분 / 바꿀 부분
- 가져올 것: 기사 수 배지, 카드(썸네일+시각+헤드라인+설명) 구성, 헤더의 Sign in 위치, 카테고리 탭.
- 바꿀 것: 탭 대신 6섹션 동시 표시, Top 5 순위, 날짜 선택기, 북마크 버튼 신규, 불필요한 토픽 태그/선거 컬렉션 제거, 썸네일은 선택.

### 화면 구성 (확인된 텍스트 기준)
- 헤더: 로고+태그라인, 내비(Home, For You, Local, Blindspot), 검색, 구독 링크, 지역 선택, International Edition 토글, 로그인/구독 유도 문구.

- 푸터: 회사 소개, 도움말, 앱 다운로드.
