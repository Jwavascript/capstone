# 국내 서비스 디자인 레퍼런스 조사 (뉴스 이슈 랭킹 대시보드 클론 대상)

- 조사 일자: 2026-10-07
- 조사 범위: 국내(한국어) 뉴스 포털·이슈 랭킹·AI 요약 서비스
- 대상 SPEC: 네이버 뉴스를 1일 1회 수집 → '관련기사' 묶음을 이슈로 → 6개 섹션(정치/경제/사회/생활·문화/세계/IT·과학)별 Top 5 → AI 3줄 요약·연관기사 수·대표기사 링크·북마크, 날짜 선택, 로그인, 북마크 대시보드, 모바일 세로 스택

## 확인 방법과 한계 (중요)

- 방법: WebFetch로 각 URL 접속 후 페이지를 마크다운 텍스트로 변환한 뒤 요약한 결과, 그리고 WebSearch.
- **한계 1**: WebFetch는 렌더링된 화면(픽셀)이 아니라 텍스트 구조를 소형 모델이 요약해 준 결과다. 따라서 **색상 코드, 정확한 열 수/픽셀 값, 글꼴 이름, 아이콘 모양은 직접 확인하지 못했다.** 아래 "시각 스타일"의 해당 항목은 모두 **미확인**이며, 실제 클론 전에 브라우저로 개발자도구(F12)를 열어 확인해야 한다.
- **한계 2**: 네이버 뉴스(news.naver.com)는 이 도구 환경에서 접속이 차단되어 화면을 확인하지 못했다. 네이버 관련 서술은 검색 결과 기사(저널리스트 등)에 근거한 **미확인(2차 정보)**이다.
- 표기: "확인" = 이번에 접속해 텍스트로 확인. "미확인" = 접속/검증 못 함, 사전 지식 또는 검색 결과 기반.
- 로그인 후 화면, 모바일 화면은 접속 환경상 확인하지 못했다(반응형 여부는 전부 미확인).
