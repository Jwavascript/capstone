# PLAN_backend_ex07 — 이슈 묶기 · 연관기사 수(키워드 검색)

> 이유: 랭킹 · 카드가 seed 샘플이고, 수집한 기사는 이슈가 되지 않으며, 표본 출처도 조선일보 계열 · investing_kr뿐임. 그래서 수집에 전체 출처 페이지를 섞고, 명령 한 번(`npm run group`)으로 그날 기사를 제목 규칙으로 묶고 대표 낱말 2개를 제목에서 검색해 1쪽 결과로 검증한 연관기사 수를 `issues`에 저장하며, 실제 DB의 샘플을 지워 화면이 실제 이슈 · 실제 갱신 시각을 보여 줌(테스트는 저장한 응답으로 네트워크 없이). 1차는 흔한 낱말에 끌려 순위가 망가져(wor `ai` 7,221건 · eco `정부`+`부동산`으로 다른 사건이 묶임) D11 · D13을 고쳐 묶기 · 검색 규칙만 다시 만듦.
> 코드 폴더: `ex07/` (1차 `ex07/` 그대로에서 고침)
> SPEC 근거: US-02 · AC-02-1 · AC-02-2 · AC-05-1(실제 갱신 시각) · AC-01-2(실패 섹션은 직전 결과로 보여 줌, D8) · AC-01-1(출처 섞기, D12)
